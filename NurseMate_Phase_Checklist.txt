========================================================
USER ROLES
========================================================
student  — Default role for all new signups. Can access all study features.
           Cannot access /admin page.

admin    — Set manually in Supabase profiles table.
           Can access /admin CMS, manage content, see all user stats.
           Admin nav link only shows in sidebar for admin accounts.

To promote a user to admin:
  UPDATE public.profiles SET role = 'admin' WHERE email = 'user@email.com';
